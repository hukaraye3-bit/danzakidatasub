# VELMORA Data Sub

Public customer launch page for VELMORA Data Sub.

## GitHub Pages
The repository is configured as a static PWA shell. Enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Important
The Google AI Studio export supplied for this deployment is a browser snapshot (MHTML), not the original React/Vite source tree. Therefore this repository contains a safe public launch/PWA shell rather than claiming that the unrecoverable source/backend has been reconstructed.

The live AI Studio preview URL referenced by the supplied project is linked from the launch page. Do not place Paystack secret keys, bank credentials, or other private credentials in client-side files.
